1. Instalar un Sistema Manejador de Bases de Datos (SMBD) junto con su motor de base de datos. Crear un manual detallado del proceso.

2. Usar Docker para instalar motores de bases de datos en contenedores con puertos diferentes (se sugiere 3307, 3308, 3309). En el video, se debe demostrar cómo, al autenticarse en cada contenedor, se accede a una base de datos distinta.

    **Requisitos:**
    - Cada base de datos debe incluir al menos tres entidades relacionadas entre sí.
    - Cada entidad debe contener un mínimo de cinco registros.

    **Entregables:**
    1. Manual del punto 1.
    2. Enlace al video demostrativo.
    3. Carpeta con los archivos de configuración de los contenedores.
    4. Código generado para las bases de datos (DDL y DML).
